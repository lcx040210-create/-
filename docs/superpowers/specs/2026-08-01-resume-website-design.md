# Rick and Morty 风格简历网站 — 设计文档

## 概述

将李成蹊的 Web3 综合简历做成单页网站，以 Rick and Morty 动画风格为主题，支持中英文切换，部署到 GitHub Pages。

## 目标

- 展示简历内容，视觉采用 Rick and Morty 实验室/传送门风格
- 中英双语一键切换，切换时有传送门扩散动画
- 全场景互动：粒子背景、控制台 UI、角色彩蛋、视差滚动
- 响应式适配桌面、平板、手机
- 纯静态 HTML/CSS/JS，零依赖，直接部署 GitHub Pages

## 模块详细设计

### 1. Canvas 粒子背景 (`script.js`)

- 80% 慢速浮动绿色粒子（50-80 个）
- 15% 偶尔出现的传送门漩涡（1-2 个，随机位置，持续 3-5 秒消失）
- 5% 随机 Rick/Morty 像素小人在边缘走动
- 全屏固定，z-index 最低层

### 2. i18n 方案

- 每个文本容器使用 `data-en` 和 `data-zh` 属性存储双语内容
- 语言切换时 JS 遍历所有 `[data-en][data-zh]` 元素替换 `textContent`
- 语言偏好存入 `localStorage`
- 切换动画：传送门绿色漩涡从按钮位置扩散到全屏（CSS `clip-path` + `transition`），300ms 后替换文本，漩涡收回

### 3. 控制台 UI 卡片

- 每个 section 卡片四角有 `┌┐└┘` 装饰伪元素
- 边框使用 `1px solid rgba(151, 206, 76, 0.3)`
- Hover 时边框颜色过渡到 `rgba(151, 206, 76, 0.8)` + 微弱 `box-shadow` 绿光
- 卡片标题使用扫描线效果（CSS `::after` 伪元素半透明条纹）

### 4. Rick 彩蛋系统

- **吐槽气泡**：右下角固定定位，随机触发（15-25 秒间隔），Rick 风格语录，5 秒后自动消失
- **传送门枪光标**：仅在 Hero 区域，`cursor: url('data:image/svg+xml,...')` 自定义光标
- **Morty 动画**：随机在页面边缘出现一个走动的 Morty 像素小人（CSS sprite animation），3 秒后跑出屏幕

### 5. 响应式断点

| 断点 | 布局 |
|------|------|
| ≥1200px | 完整桌面布局，5 列能力卡 |
| 768-1199px | 2 列能力卡，卡片全宽 |
| <768px | 单列，导航简化，粒子减少到 30 个 |

### 6. 滚动效果

- 左侧固定进度线（传送门绿色），随滚动增长
- 卡片进入视口时 `fadeInUp` 动画（Intersection Observer）

## 不做的

- 无后端、无数据库、无 CMS
- 无 PDF 导出
- 无 Rick and Morty 官方素材（版权风险），仅用配色 + 原创 CSS/SVG
- 无复杂粒子物理引擎（保持轻量）
