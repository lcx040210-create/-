# 北岭闸口 · 画面 Prompt 库

> 框架：窗边处决演出、伪人非真人、定格恐怖片。
> 主体 = 设施里的替换体（doppelganger / impostor creature），**不写现实杀人教程**。
> 英文提示词直接丢图生/视频模型；中文是镜头说明。

## 通用前缀（每条都加）

```
first-person horror game cutscene, looking through a reinforced checkpoint window, 1990s research outpost, grimy glass, fluorescent flicker, stop-motion creature that only looks human, not a real person, practical gore effects, wet viscera and dark arterial spray as alien tissue, cinematic lighting, grain, VHS, no text, no watermark
```

## 通用后缀

```
horror game cinematic, grotesque but stylized, creature anatomy tearing apart, heavy blood mist on glass, chunks of pale tissue and black ichor, terrified atmosphere, 35mm, high detail, --ar 16:9
```

## 组合用法

- **做图**：前缀 + 一条武器 + 后缀
- **做短视频**：再加 `2 to 4 second shot, 12fps stop-motion, smear frames, camera shake, blood hits lens`
- **San 低「错杀幻觉」**：任意一条末尾加 `plus brief hallucination overlay: the face looks fully human for one frame then snaps back to wrong anatomy`

## 过审替换

平台审暴力时：`blood` → `black ichor`，`viscera` → `alien pulp`，主体始终写 `doppelganger / impostor creature`，过审率更高。
